tkinter.systray — 시스템 트레이 아이콘 및 알림¶

소스 코드: Lib/tkinter/systray.py

Added in version 3.16.0a0 (unreleased).

tkinter.systray 모듈은 시스템 트레이(또는 작업 표시줄) 아이콘에 대한 인터페이스로 SysTrayIcon 클래스와 데스크톱 알림을 보내는 notify() 함수를 제공합니다. 이들은 Tk 8.7/9.0 이상이 필요합니다.

Tcl 인터프리터 하나당 하나의 시스템 트레이 아이콘만 지원됩니다.

class tkinter.systray.SysTrayIcon(master=None, *, exists=False, **options)¶

시스템 트레이 아이콘을 구현하는 클래스입니다.

exists 가 false(기본값)인 경우 새 아이콘이 생성되며, 두 번째 아이콘을 생성하려고 하면 TclError 가 발생합니다. exists 가 true인 경우 인스턴스는 새 아이콘을 만드는 대신 이미 존재하는 아이콘을 참조하며, 주어진 옵션으로 재구성합니다.

지원되는 구성 옵션은 다음과 같습니다:

  • image — 시스템 트레이에 표시되는 이미지(아이콘 생성 시 필요). Windows에서는 반드시 PhotoImage 여야 합니다.

  • text — 아이콘의 툴팁에 표시되는 텍스트입니다.

  • button1 — 아이콘을 마우스 왼쪽 버튼으로 클릭했을 때 인자 없이 호출되는 콜백입니다.

  • button3 — 아이콘을 마우스 오른쪽 버튼으로 클릭했을 때 인자 없이 호출되는 콜백입니다.

configure(**options)¶
config(**options)¶

시스템 트레이 아이콘의 옵션을 조회하거나 수정합니다. 인자가 없으면 모든 옵션 값이 포함된 딕셔너리를 반환합니다. 문자열 인자가 있으면 해당 옵션의 값을 반환합니다. 그 외의 경우, 주어진 옵션을 설정합니다.

cget(option)¶

시스템 트레이 아이콘의 해당 옵션 값을 반환합니다.

exists()¶

시스템 트레이 아이콘이 존재하는지 여부를 반환합니다.

destroy()¶

시스템 트레이 아이콘을 제거합니다. 그 후에 새 아이콘을 생성할 수 있습니다.

notify(title, message)¶

지정된 제목과 메시지가 포함된 데스크톱 알림을 보냅니다.

tkinter.systray.notify(title, message, *, master=None)¶

시스템 트레이 아이콘을 먼저 생성하지 않고 지정된 제목과 메시지로 데스크톱 알림을 보냅니다. Windows에서는 알림을 보내려면 기존 시스템 트레이 아이콘이 필요하며, 이 아이콘은 알림에도 표시됩니다. 대신 SysTrayIcon.notify() 메서드를 사용하십시오.
