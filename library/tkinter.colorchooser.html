tkinter.colorchooser — 색상 선택 대화 상자¶

소스 코드: Lib/tkinter/colorchooser.py

tkinter.colorchooser 모듈은 네이티브 색상 선택기 대화 상자의 인터페이스로 Chooser 클래스를 제공합니다. Chooser``는 모달(modal) 방식의 색상 선택 대화 상자 창을 구현하며, ``Chooser 클래스는 Dialog 클래스를 상속받습니다.

class tkinter.colorchooser.Chooser(master=None, **options)¶

모달 색상 선택 대화 상자를 구현하는 클래스입니다. 대부분의 애플리케이션은 이 클래스를 직접 인스턴스화하는 대신 편리한 기능인 askcolor() 함수를 사용합니다.

tkinter.colorchooser.askcolor(color=None, **options)¶

모달 색상 선택 대화 상자를 표시하고 선택된 색상을 반환합니다. color 는 대화 상자가 열릴 때 선택된 색상입니다. 반환 값은 튜플 ((r, g, b), hexstr) 이며, 여기서 r, g, b 는 0~255 범위의 정수 형태인 빨강, 녹색, 파랑 성분이고 hexstr 은 '#ff8000' 과 같은 동일한 Tk 색상 문자열입니다. 사용자가 대화 상자를 취소하면 (None, None) 이 반환됩니다.

버전 3.10에서 변경: 반환된 색상의 RGB 값은 이제 부동 소수점이 아닌 0–255 범위의 정수입니다.
