tkinter.fontchooser — 글꼴 선택 대화 상자¶

Added in version 3.16.0a0 (unreleased).

소스 코드: Lib/tkinter/fontchooser.py

tkinter.fontchooser 모듈은 네이티브 글꼴 선택 대화 상자의 인터페이스로 FontChooser 클래스를 제공합니다.

글꼴 대화 상자는 애플리케이션 전체에 적용됩니다. Tcl 인터프리터당 하나의 글꼴 대화 상자가 있으며, 모든 FontChooser 인스턴스가 동일한 대화 상자를 구성합니다.

플랫폼에 따라 대화 상자가 모달(modal) 또는 모달리스(modeless)일 수 있으므로, show() 가 즉시 반환될 수 있습니다. 선택된 글꼴은 직접 반환되지 않고, command 옵션으로 지정된 콜백에 Font 객체로 전달됩니다.

대화 상자는 부모 창(parent 옵션 참조)에서 두 개의 가상 이벤트를 생성합니다.

<<TkFontchooserVisibility>>

대화 상자가 표시되거나 숨겨질 때 생성됩니다. 어떤 경우인지 확인하려면 visible 옵션을 조회하십시오.

<<TkFontchooserFontChanged>>

선택된 글꼴이 변경될 때 생성됩니다.

참고

command 콜백은 선택된 글꼴을 얻는 유일하게 확실한 방법입니다. 일부 플랫폼에서는 font 옵션이 사용자의 선택으로 업데이트되지 않을 수 있습니다.

class tkinter.fontchooser.FontChooser(master=None, **options)¶

글꼴 선택 대화 상자를 구현하는 클래스입니다.

master 는 대화 상호를 소유하는 Tcl 인터프리터의 위젯입니다. 생략할 경우, parent 가 제공되었다면 parent 를 기본값으로 사용하고, 그렇지 않으면 기본 루트 창을 사용합니다.

지원되는 구성 옵션은 다음과 같습니다:

  • parent — 대화 상자 및 관련 가상 이벤트가 연결되는 창입니다. 기본값은 메인 창이며, macOS에서는 독립된 패널이 아닌 해당 창에 부착된 시트(sheet) 형태로 표시됩니다.

  • title — 대화 상자의 제목입니다.

  • font — 현재 대화 상자에서 선택된 글꼴입니다.

  • command — 사용자가 글꼴을 선택할 때 선택된 글꼴을 래핑한 Font 객체와 함께 호출되는 콜백입니다.

  • visible — 대화 상자가 현재 표시되고 있는지 여부(읽기 전용).

font 옵션은 tkinter.font.Font 에서 지원하는 형식을 허용합니다.

configure(**options)¶
config(**options)¶

글꼴 대화 상자의 옵션을 조회하거나 수정합니다. 인자가 없으면 모든 옵션 값이 포함된 딕셔너리를 반환합니다. 문자열 인자가 있으면 해당 옵션의 값을 반환합니다. 그 외의 경우, 주어진 옵션을 설정합니다.

cget(option)¶

글꼴 대화 상자의 해당 옵션 값을 반환합니다.

show()¶

글꼴 대화 상자를 표시합니다. 플랫폼에 따라 이 메서드가 즉시 반환되거나 대화 상자가 닫힌 후에야 반환될 수 있습니다.

hide()¶

글꼴 대화 상자가 표시 중인 경우 숨깁니다.
