tkinter.dnd — 드래그 앤드 드롭 지원¶

소스 코드: Lib/tkinter/dnd.py

참고

이것은 실험적이며 Tk DND로 대체될 때 폐지될 예정입니다.

tkinter.dnd 모듈은 단일 응용 프로그램 내에서, 같은 창 내 또는 창 사이의 객체에 대한 드래그 앤드 드롭 지원을 제공합니다. 객체를 드래그할 수 있게 하려면, 드래그 앤드 드롭 프로세스를 시작하는 이벤트 바인딩을 생성해야 합니다. 일반적으로 작성한 콜백 함수에 ButtonPress 이벤트를 바인딩합니다 (바인딩 및 이벤트 참조). 해당 함수는 dnd_start() 를 호출해야 하며, 여기서 source 는 드래그할 객체이고 event 는 호출을 유발한 이벤트(콜백 함수의 인자)입니다.

대상 객체는 다음과 같이 선택됩니다:

  1. 대상 위젯을 찾기 위해 마우스 아래 영역을 하향식으로 검색:

    • 대상 위젯은 호출 가능한 dnd_accept 어트리뷰트를 가져야 합니다.

    • dnd_accept 가 없거나 None 을 반환하는 경우, 검색은 부모 위젯으로 이동합니다.

    • 대상 위젯을 찾지 못한 경우, 대상 객체는 None 입니다.

  2. <old_target>.dnd_leave(source, event) 호출.

  3. <new_target>.dnd_enter(source, event) 호출.

  4. 드롭을 알리기 위해 <target>.dnd_commit(source, event) 를 호출합니다.

  5. 드래그 앤드 드롭의 종료를 알리기 위해 <source>.dnd_end(target, event) 를 호출합니다.

class tkinter.dnd.DndHandler(source, event)¶

DndHandler 클래스는 이벤트 위젯의 루트에서 Motion과 ButtonRelease 이벤트를 추적하는 드래그 앤드 드롭 이벤트를 처리합니다.

cancel(event=None)¶

드래그 앤드 드롭 프로세스를 취소합니다.

finish(event, commit=0)¶

드래그 앤드 드롭 기능의 끝을 실행합니다.

on_motion(event)¶

드래그가 수행되는 동안 마우스 아래의 영역에서 대상 객체를 확인합니다.

on_release(event)¶

릴리즈 패턴이 트리거 될 때 드래그의 끝을 알립니다.

tkinter.dnd.dnd_start(source, event)¶

드래그 앤 드롭 프로세스를 위한 팩토리 함수입니다. 드래그를 관리하는 DndHandler 인스턴스를 반환하거나, 드래그를 시작할 수 없는 경우 None 을 반환합니다.
