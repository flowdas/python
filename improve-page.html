문서 페이지 개선하기¶

저희는 문서 개선에 대한 아이디어를 항상 환영합니다.

<PAGEURL>에서 “PAGETITLE”을 읽고 계십니다. 해당 페이지의 소스는 GitHub <https://github.com/python/cpython/blob/main/Doc/PAGESOURCE?plain=1> 에 있습니다.

질문이나 변경 사항을 제안하는 몇 가지 방법이 있습니다:

  • Python 토론 포럼에서 해당 페이지에 관한 논의를 시작할 수 있습니다. 이 링크를 클릭하면 미리 채워진 주제로 토론이 시작됩니다: 페이지 “PAGETITLE”에 대한 질문.

  • Python GitHub 이슈 추적기에서 이슈를 열 수 있습니다. 이 링크는 미리 채워진 새 이슈를 생성합니다: Docs: 문제 발생 페이지 “PAGETITLE”.

  • GitHub에서 페이지 편집 <https://github.com/python/cpython/blob/main/Doc/PAGESOURCE?plain=1> 을 통해 풀 리퀘스트를 생성하고 기여 프로세스를 시작할 수 있습니다.
