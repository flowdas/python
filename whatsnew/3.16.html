Python 3.16의 새로운 기능에 대해 알아봅시다¶

편집기:

추후 결정

이 문서는 파이썬 3.15와 비교한 파이썬 3.16의 새로운 기능들을 설명합니다.

For full details, see the changelog.

참고

프리릴리스 사용자는 이 문서가 현재 초안 형식임을 인지해야 하며, Python 3.16 출시로 향함에 따라 상당한 업데이트가 있을 예정이므로 이전 버전을 읽은 후에도 다시 확인해 볼 가치가 있습니다.

새로운 기능¶

기타 언어 변경 사항들¶

새 모듈¶

  • 아직 없음.

개선된 모듈¶

curses¶

  • curses.filter() 의 효과를 취소하는 curses.nofilter() 를 추가합니다. (Serhiy Storchaka가 gh-151744 에서 기여함.)

gzip 모듈¶

  • gzip.open() now accepts an optional argument mtime which is passed on to the constructor of the GzipFile class. (Contributed by Marin Misur in gh-91372.)

lzma¶

  • lzma.FILTER_ARM64 와 lzma.FILTER_RISCV 를 통해 새로운 BCJ 필터 ARM64 및 RISC-V를 지원합니다. 새 필터는 런타임 라이브러리가 이를 지원하는 경우에만 작동한다는 점에 유의하세요. ARM64 필터는 lzma 5.4.0 이상을 필요로 하는 반면, RISC-V는 5.6.0 이상을 필요로 합니다. (Chien Wong이 gh-115988 에서 기여했습니다.)

logging 모듈¶

  • TimedRotatingFileHandler now uses the creation time instead of the last modification time of an existing log file as the basis for the first rotation after handler creation, if supported by the OS and file system. This allows it to be used in short-running programs that start and end before the rotation interval expires. (Contributed by Iván Márton and Serhiy Storchaka in gh-84649.)

math 모듈¶

  • 라디안 단위가 아닌 반 사이클 단위로 작동하는 삼각 함수를 추가했습니다. 새로운 함수인 math.acospi(), math.asinpi(), math.atanpi(), 그리고 math.atan2pi() 는 반 사이클 각도를 반환합니다. 새로운 함수인 math.cospi(), math.sinpi(), 및 math.tanpi() 는 반 사이클 각도 인수를 받습니다. 이 함수들은 IEEE 754-2019에서 권장되고 C23에서 표준화되었습니다. (Jeff Epler가 gh-150534 에서 기여했습니다.)

os¶

  • Add os.pidfd_getfd() for duplicating a file descriptor from another process via a pidfd. Available on Linux 5.6+. (Contributed by Maurycy Pawłowski-Wieroński in gh-149464.)

shlex¶

  • 따옴표 없이도 셸에 안전한 문자열이라 하더라도 강제로 따옴표를 사용하도록 shlex.quote() 에 키워드 전용 매개변수 force 를 추가했습니다. (Jay Berry가 gh-148846 에서 기여했습니다.)

tkinter¶

  • undo 또는 redo가 가능한지 여부를 반환하는 새로운 tkinter.Text 메서드인 edit_canundo() 및 edit_canredo() 를 추가했습니다. (Serhiy Storchaka가 gh-151674 에서 기여하였습니다.)

  • 표시된 뷰와 기본 텍스트 간의 동기화를 제어하고 보고하는 새로운 tkinter.Text 메서드인 sync() 및 pendingsync() 를 추가했습니다. (Serhiy Storchaka가 gh-151675 에서 기여했습니다.)

xml¶

  • Add support for multiple multi-byte encodings in the XML parser: “cp932”, “cp949”, “cp950”, “Big5”,”EUC-JP”, “GB2312”, “GBK”, “johab”, and “Shift_JIS”. Add partial support (only BMP characters) for multi-byte encodings “Big5-HKSCS”, “EUC_JIS-2004”, “EUC_JISX0213”, “Shift_JIS-2004”, “Shift_JISX0213”, “utf-8-sig” and non-standard aliases like “UTF8” (without hyphen). The parser now raises ValueError for known unsupported multi-byte encodings such us “ISO-2022-JP” or “raw-unicode-escape” instead of failing later, when encounter non-ASCII data. (Contributed by Serhiy Storchaka in gh-62259.)

zipfile¶

  • 아카이브의 중앙 디렉터리에서 멤버를 제거하는 ZipFile.remove() 와, 제거된 멤버의 로컬 파일 항목이 사용하던 공간을 회수하는 ZipFile.repack() 를 추가합니다. (Danny Lin이 gh-51067 에서 기여함.)

제거됨¶

annotationlib¶

  • The annotationlib.ForwardRef._evaluate() method which has been deprecated since Python 3.14. Use annotationlib.ForwardRef.evaluate() or typing.evaluate_forward_ref() instead.

배열(array)¶

  • 문서에서는 파이썬 3.3부터, 런타임에서는 파이썬 3.13부터 사용 지원 중단된 'u' 포맷 코드 (wchar_t)를 사용하지 마십시오. 대신 'w' 포맷 코드 (Py_UCS4, 항상 4바이트)를 사용하십시오.

asyncio¶

  • The asyncio.iscoroutinefunction() which has been deprecated since Python 3.14. Use inspect.iscoroutinefunction() instead.

functools 모듈¶

  • Calling the Python implementation of functools.reduce() with function or sequence as keyword arguments has been deprecated since Python 3.14.

logging 모듈¶

  • strm 인자를 이용한 사용자 정의 로깅 처리기 지원은 사용 지원 중단되었으며 파이썬 3.16에서 제거될 예정입니다. 대신 stream 인자를 사용하여 처리기를 정의하십시오.

mimetypes¶

  • Valid extensions start with a ‘.’ or are empty for mimetypes.MimeTypes.add_type(). Undotted extensions now raise a ValueError.

shutil 모듈¶

  • :exc`:exc:!ExecError 예외는 파이썬 3.14부터 사용 지원 중단(deprecated)되었습니다. :mod`:mod:!shutil 의 어떤 함수에서도 파이썬 3.4 이후로 사용되지 않았습니다. (Stan Ulbrych가 gh-149567 \을 통해 기능을 구현하였습니다.)

심볼테이블¶

  • :meth`:meth:!symtable.Class.get_methods 메서드는 파이썬 3.14부터 사용 지원 중단(deprecated)되었습니다.

sys 모듈¶

  • The _enablelegacywindowsfsencoding() function which has been deprecated since Python 3.13. Use the PYTHONLEGACYWINDOWSFSENCODING environment variable instead. (Contributed by Stan Ulbrych in gh-149595.)

sysconfig 모듈¶

  • The sysconfig.expand_makefile_vars() function which has been deprecated since Python 3.14. Use the vars argument of sysconfig.get_paths() instead. (Contributed by Stan Ulbrych in gh-149499.)

타르파일¶

  • 문서화되지도 사용되지도 않은 :attr`:attr:!tarfile.TarFile.tarfile 어트리뷰트는 파이썬 3.13부터 사용 지원 중단(deprecated)되었습니다.

사용 지원 중단됨¶

  • abc

    • Soft-deprecated since Python 3.3 abc.abstractclassmethod, abc.abstractstaticmethod, and abc.abstractproperty now raise a DeprecationWarning. These classes will be removed in Python 3.21, instead use abc.abstractmethod() with classmethod(), staticmethod(), and property respectively.

  • ast:

    • 파이썬 3.9부터 폐지된 클래스인 slice, Index, ExtSlice, Suite, Param, AugLoad 및 `AugStore 는 더 이상 from ast import * 에 의해 가져와지지 않으며 사용 시 폐기 경고를 발생시킵니다. 이 클래스들은 파이썬 3.21에 제거될 예정입니다. 이러한 타입은 파서에 의해 생성되지 않았거나 코드 생성기에 의해 받아들여지지 않습니다.

    • 파이썬 3.9부터 폐지된 ast.Tuple 객체의 dims 속성은 사용 시 폐기 경고를 발생시킵니다. 이 속성은 3.21에 제거될 예정입니다. 대신 ast.Tuple.elts 를 사용하십시오.

파이썬 3.17에서 제거 예정임¶

  • datetime:

    • 연도 정보가 없는 ``%e``(월의 일)를 포함하는 형식 문자열을 사용하는 strptime() 호출은 파이썬 3.15부터 사용 지원 중단되었습니다. (Stan Ulbrych가 gh-70647 를 통해 기능을 구현하였습니다.)

  • :mod:`collections.abc`:

    • :class:`collections.abc.ByteString`은 파이썬 3.17에서 제거될 예정입니다.

      실행 시점에 obj 가 buffer protocol 를 구현하는지 확인하려면 isinstance(obj, collections.abc.Buffer)``를 사용하십시오. 타입 어노테이션에서 사용하는 경우, :class:`~collections.abc.Buffer` 또는 코드가 지원하는 유형을 명시적으로 지정하는 유니언(예: ``bytes | bytearray | memoryview)을 사용하십시오.

      ByteString`은 원래 :class:`bytes`와 :class:`bytearray 모두의 상위 타입 역할을 하는 추상 클래스로 의도되었습니다. 그러나 이 ABC는 어떠한 메서드도 포함하지 않았기 때문에, 객체가 ByteString 인스턴스라는 사실을 알게 되어도 해당 객체에 대해 유용한 정보를 제공하지 못했습니다. 또한 memoryview`와 같은 다른 일반적인 버퍼 타입들도 (실행 시점이나 정적 타입 검사기에서) :class:!ByteString`의 하위 타입으로 인식되지 않았습니다.

      더 자세한 내용은 PEP 688 를 참고하십시오. (Shantanu Jain이 :gh:`91896`를 통해 기여했습니다.)

  • encodings:

    • encodings.normalize_encoding`에 비ASCII *encoding* 이름을 전달하는 것은 사용 지원 중단되었으며 파이썬 3.17에서 제거될 예정입니다. (Stan Ulbrych가 :gh:`136702() 를 통해 기능을 구현하였습니다.)

  • webbrowser:

    • webbrowser.MacOSXOSAScript`는 :class:!webbrowser.MacOS`를 대신하여 사용 지원 중단되었습니다. (gh-137586)

  • typing:

    • 파이썬 3.14 이전에는 구형 스타일의 유니언(union)을 비공개 클래스 ``typing._UnionGenericAlias``를 사용하여 구현했습니다. 이 클래스는 더 이상 구현에 필요하지 않지만, 하위 호환성을 위해 유지되어 왔으며 파이썬 3.17에서 제거될 예정입니다. 사용자는 비공개 구현 세부 사항에 의존하는 대신 typing.get_origin() 및 :func:`typing.get_args`와 같은 문서화된 인트로스펙션 도우미를 사용해야 합니다.

    • :class:`typing.ByteString`은 파이썬 3.9부터 사용 지원 중단되었으며 파이썬 3.17에서 제거될 예정입니다.

      실행 시점에 obj 가 buffer protocol 를 구현하는지 확인하려면 isinstance(obj, collections.abc.Buffer)``를 사용하십시오. 타입 어노테이션에서 사용하는 경우, :class:`~collections.abc.Buffer` 또는 코드가 지원하는 유형을 명시적으로 지정하는 유니언(예: ``bytes | bytearray | memoryview)을 사용하십시오.

      ByteString`은 원래 :class:`bytes`와 :class:`bytearray 모두의 상위 타입 역할을 하는 추상 클래스로 의도되었습니다. 그러나 이 ABC는 어떠한 메서드도 포함하지 않았기 때문에, 객체가 ByteString 인스턴스라는 사실을 알게 되어도 해당 객체에 대해 유용한 정보를 제공하지 못했습니다. 또한 memoryview`와 같은 다른 일반적인 버퍼 타입들도 (실행 시점이나 정적 타입 검사기에서) :class:!ByteString`의 하위 타입으로 인식되지 않았습니다.

      더 자세한 내용은 PEP 688 를 참고하십시오. (Shantanu Jain이 :gh:`91896`를 통해 기여했습니다.)

파이썬 3.18에서 제거 예정인 항목들¶

  • 파일 디스크립터가 예상되는 경우 부울(boolean) 값은 더 이상 허용되지 않습니다. (Serhiy Storchaka가 gh-82626\을 통해 기능을 구현하였습니다.)

  • decimal`:

    • 비표준적이고 문서화되지 않은 Decimal 형식 지정자 ``’N’``는 decimal 모듈의 C 구현에서만 지원되었으며 Python 3.13부터 폐지되었습니다. (Serhiy Storchaka가 gh-89902\을 통해 기능을 구현하였습니다.)

  • :pep:`829`에 의해 정의된 폐지 사항:

    • name.pth 파일의 import 라인은 조용히 무시됩니다.

    (Barry Warsaw가 gh-148641 를 통해 기능을 구현하였습니다.)

파이썬 3.19에서 제거 예정임¶

  • ctypes`:

    • 윈도우가 아닌 플랫폼에서 :attr:`~ctypes.Structure._layout_`를 설정하지 않고 :attr:`~ctypes.Structure._pack_`를 설정하여 MSVC 호환 구조체 레이아웃으로 암시적으로 전환하는 경우입니다.

  • hashlib:

    • new() 또는 md5() 및 sha256`와 같은 해시 함수 생성자에서, 선택적인 초기 데이터 매개변수로 다양한 :mod:()!hashlib` 구현체들에서는 data= 또는 ``string=``라는 이름의 키워드 인자가 전달될 수도 있습니다.

      string 키워드 인자 이름에 대한 지원은 이제 폐지되었으며 파이썬 3.19에서 제거될 예정입니다.

      파이썬 3.13 이전에는 해시 함수의 백엔드 구현에 따라 string 키워드 매개변수가 올바르게 지원되지 않았습니다. 최대의 하위 호환성을 위해 초기 데이터를 위치 인자로 전달하는 것을 권장합니다.

  • http.cookies:

    • http.cookies.Morsel.js_output() 은 폐지되었으며 파이썬 3.19에서 제거될 예정입니다.

    • http.cookies.BaseCookie.js_output() 은 폐지되었으며 파이썬 3.19에서 제거될 예정입니다.

  • imaplib:

    • IMAP4.file 를 변경하는 것은 이제 폐지되었으며 파이썬 3.19에서 제거될 예정입니다. 이 속성은 이제 사용되지 않으며 값을 변경해도 현재 파일을 자동으로 닫지 않습니다.

      파이썬 3.14 이전에는 이 속성이 IMAP4`를 위한 대응하는 ``read()` 및 readline() 메서드를 구현하는 데 사용되었으나, 그 이후로는 더 이상 그렇지 않습니다.

파이썬 3.21에서 제거 예정인 항목들¶

  • abc

    • Soft-deprecated since Python 3.3 abc.abstractclassmethod, abc.abstractstaticmethod, and abc.abstractproperty now raise a DeprecationWarning. These classes will be removed in Python 3.21, instead use abc.abstractmethod() with classmethod(), staticmethod(), and property respectively.

  • ast:

    • slice, Index, ExtSlice, Suite, Param, AugLoad 및 AugStore 클래스는 파이썬 3.21에서 제거될 예정입니다. 이 타입들은 파서에 의해 생성되지 않거나 코드 생성기에 의해 허용되지 않습니다.

    • ast.Tuple``의 ``dims 속성은 파이썬 3.21에서 제거될 예정입니다. 대신 ast.Tuple.elts 속성을 사용하십시오.

미래 버전에서 제거 예정입니다¶

다음의 API는 미래에 제거될 예정이지만, 현재로서는 구체적인 제거 일정이 정해지지 않았습니다.

  • :mod:`argparse`

    • 인자 그룹 중첩 및 상호 배타적인 그룹의 중첩이 사용 지원 중단(deprecated)되었습니다.

    • :meth:`~argparse.ArgumentParser.add_argument_group`에 문서화되지 않은 키워드 인자 prefix_chars 를 전달하는 방식은 이제 폐지되었습니다.

    • argparse.FileType 타입 변환기가 폐지되었습니다.

  • builtins:

    • 제너레이터: throw(type, exc, tb) 및 athrow(type, exc, tb) 시그니처는 폐지되었으며, 대신 단일 인자 시그니처인 throw(exc) 및 athrow(exc) 를 사용하십시오.

    • 현재 파이썬은 숫자 리터럴 뒤에 키워드가 바로 이어지는 것을 허용합니다 (예: 0in x, 1or x, 0if 1else 2). 이는 [0x1for x in y]``와 같이 혼란스럽고 모호한 표현을 허용하며, 이는 ``[0x1 for x in y] 또는 ``[0x1f or x in y]``로 해석될 수 있습니다. 숫자 리터럴이 키워드 and, else, for, if, in, is 및 or 중 하나와 바로 인접하게 이어지는 경우 구문 경고(syntax warning)가 발생합니다. 향후 출시 버전에서 이는 구문 오류로 변경될 예정입니다. (gh-87999)

    • 비정수(non-int) 유형을 반환하는 __index__() 및 __int__() 메서드 지원: 이 메서드들은 :class:`int`의 엄격한 하위 클래스(strict subclass) 인스턴스를 반환하도록 요구됩니다.

    • float`의 엄격한 하위 클래스(strict subclass)를 반환하는 ``__float__()` 메서드 지원: 이 메서드들은 float 인스턴스를 반환하도록 요구됩니다.

    • complex`의 엄격한 하위 클래스(strict subclass)를 반환하는 ``__complex__()` 메서드 지원: 이 메서드들은 complex 인스턴스를 반환하도록 요구됩니다.

    • complex() 생성자에서 real 또는 imag 인자로 복소수를 전달하는 방식은 이제 폐지되었으며; 이는 단일 위치 인자로만 전달되어야 합니다. (Serhiy Storchaka가 :gh:`109218`를 통해 기여하였습니다.)

  • calendar: calendar.January 및 calendar.February 상수는 폐지되었으며 calendar.JANUARY 및 :data:`calendar.FEBRUARY`로 대체됩니다. (Prince Roshan이 :gh:`103636`를 통해 기여했습니다.)

  • codecs: codecs.open() 대신 open`을 사용하십시오. (:gh:`133038())

  • codeobject.co_lnotab: 대신 codeobject.co_lines() 메서드를 사용하십시오.

  • datetime:

    • utcnow(): 대신 ``datetime.datetime.now(tz=datetime.UTC)``를 사용하십시오.

    • utcfromtimestamp(): 대신 ``datetime.datetime.fromtimestamp(timestamp, tz=datetime.UTC)``를 사용하십시오.

  • :mod:`gettext: 복수형 값은 정수여야 합니다.`

  • :mod:`importlib`

    • :func:`~importlib.util.cache_from_source`의 debug_override 매개변수가 폐지되었습니다: 대신 optimization 매어변수를 사용하십시오.

  • :mod:`importlib.metadata`

    • EntryPoints 튜플 인터페이스.`

    • 반환 값에 암시적으로 ``None``을 사용합니다.

  • logging: warn() 메서드는 Python 3.3부터 폐지되었으며, 대신 :meth:`~logging.warning`을 사용하십시오.

  • :mod:`mailbox: StringIO 입력과 텍스트 모드 사용은 폐지되었으므로, 대신 BytesIO와 바이너리 모드를 사용하십시오.`

  • os: 다중 스레드 프로세스에서 os.register_at_fork()\를 호출하는 것은 사용 지원 중단(deprecated) 되었습니다.

  • os.path: os.path.commonprefix`는 폐지되었으며, 경로 접두사의 경우 :func:`os.path.commonpath`를 사용하십시오. :func:`os.path.commonprefix() 함수는 이름과 모듈이 오해의 소지가 있어 폐지되고 있습니다. 이 함수는 경로 조작 관련 모듈에 포함되어 있음에도 불구하고 경로 접두사로 사용하기에 안전하지 않으며, 이 함수를 사용하여 파이썬 프로그램에 경로 탐색(path traversal) 취약성이 실수로 도입되기 쉽기 때문입니다.

Python 3.16으로의 이식¶

이 섹션에서는 이전에 설명된 변경 사항과 코드를 수정해야 할 수 있는 다른 버그 수정 사항을 나열합니다.

빌드 변경¶

  • 유지보수와 업데이트를 단순화하기 위해 CPython 소스 트리의 번들된 libmpdec decimal 라이브러리 복사본을 제거합니다. decimal 모듈은 이제 시스템의 libmpdec decimal 라이브러리를 무조건 사용하게 됩니다. 또한 더 이상 사용되지 않는 --with-system-libmpdec configure 플래그도 제거됩니다. 이 변경 사항은 과거 몇 번의 릴리스 동안 별도의 libmpdec 사본을 기반으로 빌드된 파이썬의 바이너리 릴리스에는 영향을 미치지 않습니다.

    (Sergey B Kirpichev가 gh-115119\를 통해 기능을 구현하였습니다.)

  • 동일한 트리에 파이썬의 여러 버전을 공동 설치하는 리눅스 배포판들이 build-details.json 충돌을 방지할 수 있도록 --with-build-details-suffix configure 플래그를 추가합니다.

    (Stefano Rivera가 gh-131372\를 통해 기능을 구현하였습니다.)
