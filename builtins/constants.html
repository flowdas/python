내장 상수¶

소수의 상수가 내장 이름 공간에 존재합니다. 해당 상수는 다음과 같습니다.

False¶

bool 타입의 거짓 값입니다. False 에 대한 대입은 허용되지 않으며 SyntaxError 를 발생시킵니다.

True¶

bool 타입의 참 값입니다. True 에 대한 대입은 허용되지 않으며 SyntaxError 를 발생시킵니다.

None¶

함수에 기본 인자가 전달되지 않을 때와 같이, 값의 부재를 나타내는 데 자주 사용되는 객체입니다. None 으로의 대입은 허용되지 않으며 SyntaxError 를 발생시킵니다. None 은 NoneType 타입의 유일한 인스턴스입니다.

NotImplemented¶

A special value which should be returned by the binary special methods (e.g. __eq__(), __lt__(), __add__(), __rsub__(), etc.) to indicate that the operation is not implemented with respect to the other type; may be returned by the in-place binary special methods (e.g. __imul__(), __iand__(), etc.) for the same purpose. It should not be evaluated in a boolean context. NotImplemented is the sole instance of the types.NotImplementedType type.

참고

이항(또는 인플레이스) 메서드가 NotImplemented`를 반환하면, 인터프리터는 다른 유형에 대해 반사된 연산을 시도합니다(연산자에 따라 다른 대체 옵션이 있을 수 있음). 모든 시도가 :data:!NotImplemented`를 반환하면 인터프리터는 적절한 예외를 발생시킵니다. 잘못된 상황에서 NotImplemented`를 반환하면 오해의 소지가 있는 에러 메시지가 출력되거나 :data:!NotImplemented` 값이 파이썬 코드로 반환됩니다.

예제는 산술 연산 구현 를 참조하십시오.

조심

NotImplemented 와 NotImplementedError 는 서로 대체하여 사용할 수 없습니다. 이 상수는 위에서 설명한 대로만 사용해야 하며, 예외의 올바른 사용에 대한 자세한 내용은 NotImplementedError 를 참조하십시오.

버전 3.9에서 변경: 불리언 컨텍스트에서 NotImplemented 를 평가하는 기능이 폐지되었습니다.

버전 3.14에서 변경: 불리언 컨텍스트에서 NotImplemented 를 평가하면 이제 TypeError 를 발생시킵니다. 이전에는 True 로 평가되었으며, 파이썬 3.9부터 DeprecationWarning 을 발생시켜 왔습니다.

Ellipsis¶

줄임표 리터럴 “... “와 동일하며, 무언가가 생략되었음을 나타내기 위해 자주 사용되는 객체입니다. Ellipsis 에 대한 대입은 가능하지만, ... 에 대한 대입은 SyntaxError 를 발생시킵니다. Ellipsis 는 types.EllipsisType 타입의 유일한 인스턴스입니다.

__debug__¶

이 상수는 파이썬이 -O 옵션과 함께 시작되지 않았을 때 True입니다. 또한 assert 문을 참조하십시오.

참고

None, False, True, __debug__ 는 재할당할 수 없으므로(속성 이름으로의 대입조차 SyntaxError 를 발생시킴) “진정한” 상수로 간주될 수 있습니다.

site 모듈에 의해 추가된 상수¶

site 모듈(음, -S 명령행 옵션이 주어지지 않는 한 시작 시 자동 임포트됨)은 내장 이름 공간에 여러 상수를 추가합니다. 이들은 대화형 인터프리터 셸에서 유용하며 프로그램 내에서는 사용해서는 안 됩니다.

quit(code=None)¶
exit(code=None)¶

인쇄할 때 “Use quit() or Ctrl-D (i.e. EOF) to exit”와 같은 메시지를 출력하고, 대화형 인터프리터에서 직접 접근하거나 함수로 호출될 때 지정된 종료 코드로 SystemExit 을 발생시키는 객체입니다.

help

인쇄할 때 “Type help() for interactive help, or help(object) for help about object.”라는 메시지를 출력하고, 대화형 인터프리터에서 직접 접근할 때 내장 도움말 시스템을 호출하는(참조: help()) 객체입니다.

copyright¶
credits¶

인쇄하거나 호출할 때 각각 저작권 또는 크레딧 텍스트를 출력하는 객체입니다.

license¶

인쇄 시 “전체 라이선스 텍스트를 보려면 license()를 입력하십시오”라는 메시지를 출력하고, 호출 시 전체 라이선스 텍스트를 페이저(pager) 스타일로(한 번에 한 화면씩) 표시하는 객체입니다.
