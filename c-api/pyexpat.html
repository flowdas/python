Expat C API¶

xml.parsers.expat 모듈은 expat_CAPI 캡슐을 통해 선택된 Expat 함수들을 노출합니다. 이를 통해 확장 모듈이 파이썬과 동일한 Expat 라이브러리를 사용할 수 있습니다. 인터페이스는 pyexpat.h`에 선언되어 있으며, 이 헤더는 Expat의 :file:`expat.h 헤더 뒤에 포함되어야 합니다.

PyExpat_CAPSULE_NAME¶

Expat C API를 포함하는 캡슐의 이름은 "pyexpat.expat_CAPI" 입니다. 이를 PyCapsule_Import() 에 전달하여 PyExpat_CAPI 에 대한 포인터를 얻을 수 있습니다.

PyExpat_CAPI_MAGIC¶

PyExpat_CAPI 의 레이아웃을 식별하는 문자열입니다. 구조체 내의 함수 포인터를 사용하기 전에 magic 멤버가 strcmp() 를 통해 이 문자열과 일치하는지, 그리고 size 멤버가 최소 sizeof(struct PyExpat_CAPI) 이상인지 확인하십시오.

struct PyExpat_CAPI¶

xml.parsers.expat 에 의해 내보낸 함수 포인터 테이블입니다. 캡슐이 이 구조를 소유하므로 읽기 전용으로 취급하고 해제하지 마십시오. 테이블을 사용하는 동안 캡슐에 대한 강력한 참조를 유지하십시오.

함수 포인터를 사용하기 전에 PyExpat_CAPI_MAGIC 에 설명된 호환성 필드를 확인하십시오.

char *magic¶

PyExpat_CAPI_MAGIC 으로 설정된 인터페이스 식별자입니다.

int size¶

구조체의 크기(바이트 단위)이며, 캡슐을 생성한 xml.parsers.expat 모듈에 의해 sizeof(struct PyExpat_CAPI) 로 설정됩니다.

xml.parsers.expat 에서 사용하는 Expat 라이브러리의 Major, minor, micro 버전 번호입니다.

void (*SetUnknownEncodingHandler)(XML_Parser parser, XML_UnknownEncodingHandler handler, void *encodingHandlerData)¶

XML_SetUnknownEncodingHandler 에 대한 포인터입니다.

int (*DefaultUnknownEncodingHandler)(void *encodingHandlerData, const XML_Char *name, XML_Encoding *info)¶

XML_SetUnknownEncodingHandler 와 함께 사용되는 Expat용 파이썬 미지정 인코딩 처리기입니다. 이 핸들러는 파이썬의 코덱 레지스트리를 사용하여 info 를 채웁니다. encodingHandlerData 인수는 사용되지 않습니다. 이 핸들러를 호출하려면 attached thread state 가 필요합니다.

해당 Expat 함수에 대한 포인터가 아래에 나열되어 있으며, xml.parsers.expat 에서 사용하는 Expat 버전에서 사용할 수 없는 경우 NULL 이 표시됩니다.

멤버 이름은 XML_ 접두사를 생략합니다. 예를 들어, SetHashSalt 는 Expat의 XML_SetHashSalt 함수를 노출합니다. 해당 함수의 동작과 나타나는 최소 Expat 버전에 대한 내용은 Expat API 레퍼런스 를 참조하십시오.
