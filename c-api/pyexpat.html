Expat C API¶

The xml.parsers.expat module exposes selected Expat functions through its expat_CAPI capsule. This allows extension modules to use the same Expat library as Python. The interface is declared in pyexpat.h, which is not included by Python.h and must be included after Expat’s expat.h header.

To use the C API, add the following code to the extension module initialization function and store the pointer to the C API in the module state:

struct PyExpat_CAPI *capi = NULL;
capi = (struct PyExpat_CAPI *)PyCapsule_Import(PyExpat_CAPSULE_NAME, 0);
if (capi == NULL) {
    goto error;
}
if (!(
     strcmp(capi->magic, PyExpat_CAPI_MAGIC) == 0
     && (size_t)capi->size >= sizeof(struct PyExpat_CAPI)
)) {
    PyErr_SetString(PyExc_ImportError, "pyexpat version is incompatible");
    goto error;
}
PyExpat_CAPSULE_NAME¶

Expat C API를 포함하는 캡슐의 이름은 "pyexpat.expat_CAPI" 입니다. 이를 PyCapsule_Import() 에 전달하여 PyExpat_CAPI 에 대한 포인터를 얻을 수 있습니다.

PyExpat_CAPI_MAGIC¶

The string identifying the layout of PyExpat_CAPI. Before using the function pointers in the structure, check that its magic member compares equal to this string using strcmp() and its size member is at least sizeof(struct PyExpat_CAPI).

struct PyExpat_CAPI¶

xml.parsers.expat 에 의해 내보낸 함수 포인터 테이블입니다. 캡슐이 이 구조를 소유하므로 읽기 전용으로 취급하고 해제하지 마십시오. 테이블을 사용하는 동안 캡슐에 대한 강력한 참조를 유지하십시오.

함수 포인터를 사용하기 전에 PyExpat_CAPI_MAGIC 에 설명된 호환성 필드를 확인하십시오.

char *magic¶

PyExpat_CAPI_MAGIC 으로 설정된 인터페이스 식별자입니다.

int size¶

구조체의 크기(바이트 단위)이며, 캡슐을 생성한 xml.parsers.expat 모듈에 의해 sizeof(struct PyExpat_CAPI) 로 설정됩니다.

int MAJOR_VERSION¶
int MINOR_VERSION¶
int MICRO_VERSION¶

Major, minor, and micro version numbers of the Expat library used by xml.parsers.expat, set to XML_MAJOR_VERSION, XML_MINOR_VERSION, and XML_MICRO_VERSION respectively.

void (*SetUnknownEncodingHandler)(XML_Parser parser, XML_UnknownEncodingHandler handler, void *encodingHandlerData)¶

XML_SetUnknownEncodingHandler 에 대한 포인터입니다.

int (*DefaultUnknownEncodingHandler)(void *encodingHandlerData, const XML_Char *name, XML_Encoding *info)¶

XML_SetUnknownEncodingHandler 와 함께 사용되는 Expat용 파이썬 미지정 인코딩 처리기입니다. 이 핸들러는 파이썬의 코덱 레지스트리를 사용하여 info 를 채웁니다. encodingHandlerData 인수는 사용되지 않습니다. 이 핸들러를 호출하려면 attached thread state 가 필요합니다.

Added in version 3.3.

해당 Expat 함수에 대한 포인터가 아래에 나열되어 있으며, xml.parsers.expat 에서 사용하는 Expat 버전에서 사용할 수 없는 경우 NULL 이 표시됩니다.

Member names omit the XML_ prefix; for example, SetHashSalt exposes Expat’s XML_SetHashSalt function. See the Expat API reference for their behavior.
