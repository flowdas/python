Expat C API¶

The xml.parsers.expat module exposes selected Expat functions through its expat_CAPI capsule. This allows extension modules to use the same Expat library as Python. The interface is declared in pyexpat.h, which must be included after Expat’s expat.h header.

PyExpat_CAPSULE_NAME¶

The name of the capsule containing the Expat C API: "pyexpat.expat_CAPI". Pass this to PyCapsule_Import() to obtain a pointer to a PyExpat_CAPI.

PyExpat_CAPI_MAGIC¶

The string identifying the layout of PyExpat_CAPI. Before using the function pointers in the structure, check that its magic member compares equal to this string using strcmp() and its size member is at least sizeof(struct PyExpat_CAPI).

struct PyExpat_CAPI¶

Table of function pointers exported by xml.parsers.expat. The capsule owns this structure: treat it as read-only and do not free it. Keep a strong reference to the capsule while using the table.

Check the compatibility fields as described under PyExpat_CAPI_MAGIC before using the function pointers.

char *magic¶

Interface identifier, set to PyExpat_CAPI_MAGIC.

int size¶

Size of the structure in bytes, set to sizeof(struct PyExpat_CAPI) by the xml.parsers.expat module that created the capsule.

int MINOR_VERSION¶
int MICRO_VERSION¶

Major, minor, and micro version numbers of the Expat library used by xml.parsers.expat.

void (*SetUnknownEncodingHandler)(XML_Parser parser, XML_UnknownEncodingHandler handler, void *encodingHandlerData)¶

Pointer to XML_SetUnknownEncodingHandler. The handler may set a Python exception on failure. The caller must check for a Python exception after parsing.

int (*DefaultUnknownEncodingHandler)(void *encodingHandlerData, const XML_Char *name, XML_Encoding *info)¶

Python’s unknown-encoding handler for Expat, used with XML_SetUnknownEncodingHandler. It uses Python’s codec registry to fill info. The encodingHandlerData argument is unused. Calling this handler requires an attached thread state.

Pointers to the corresponding Expat functions, or NULL if not available in the Expat version used by xml.parsers.expat, are listed below.

Member names omit the XML_ prefix; for example, SetHashSalt exposes Expat’s XML_SetHashSalt function. See the Expat API reference for their behavior and the minimum Expat version they appear in.
